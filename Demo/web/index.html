Event graph, newest at the bottom

Each row is a run of consecutive events by one author. Lines point from a run to the events it was based on. Two lines into one row mean that author had seen both branches: a merge.

What you're looking at

  • Each replica is a real OpLog from egwalker-swift. It stores every edit as a plain position (“insert at 5”) plus which earlier edits its author had seen.
  • Syncing is merge(from:): one replica learns the events it hasn't seen yet. Nothing is sent but events.
  • The text in each editor is produced by checkout(), which replays the history. Where edits were concurrent, it builds CRDT state for just that stretch and drops it again afterwards. The inspector shows how much of the history needed that.
  • Positions count Unicode scalars, so emoji and accents work as you'd expect. Agent names break ties when two people insert at the same spot.
